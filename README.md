# YouTube Saver

Восстановление **подписок** и **истории просмотров** на новом YouTube-канале
из выгрузки Google Takeout старого (например, заблокированного) канала.
Плюс сохранение ваших опубликованных видео и локальный архив истории.

Работает **без API-ключей** и без создания проектов в Google Cloud.

## Что умеет

| Что | Как | Насколько «нативно» |
|---|---|---|
| Подписки (из `подписки.csv`) | Оформляет подписки тем же внутренним запросом, что и кнопка «Подписаться» на сайте — из вашего собственного браузера, с вашим входом | ✅ полноценно, подписки появляются на канале |
| История просмотров (`история-просмотров.html`) | Открывает каждое видео на несколько секунд в вашем браузере — YouTube сам добавляет его в историю | ⚠️ полу-нативно: записи появляются в истории на новом канале, но с текущей датой; старые даты сохраняются только в локальном архиве |
| История поиска (`история_поиска.html`) | Локальный архив + CSV | 📄 локально (в аккаунт записать нельзя) |
| Опубликованные видео | Распаковка из архива в `data/videos/` + страница-галерея «Мои видео» | 📄 локально |

> **Почему история — так?** У YouTube нет ни официального API, ни другого
> санкционированного способа записать историю просмотров. Единственный рабочий
> приём — реально проиграть видео в залогиненном браузере (YouTube добавляет
> в историю после нескольких секунд просмотра). Сервис делает это
> автоматически: без звука, ~10–15 секунд на видео, с паузой и продолжением.

## Быстрый старт

1. Нужен **Python 3.9+** и установленный **Chrome** (или Edge/Brave).
2. Скачайте выгрузку Takeout заблокированного аккаунта:
   [takeout.google.com](https://takeout.google.com) → выбрать только «YouTube
   и YouTube Music» (обязательно с «историей», «подписками» и «видео»).
   Положите **все** zip-части в одну папку (рядом с программой — уже подходит).
3. Установите зависимость и запустите:

   ```bash
   pip install websocket-client
   python main.py
   ```

4. Откроется панель управления `http://127.0.0.1:8765`. Дальше по шагам в
   интерфейсе:

   - **Шаг 1. Браузер** — запустится отдельное окно Chrome со своим профилем.
     **Войдите в нём в ваш НОВЫЙ Google-аккаунт** (один раз). Профиль
     хранится в `data/chrome-profile` и не смешивается с вашим основным
     браузером.
   - **Шаг 2. Подписки** — снимите галочки с ненужных каналов и нажмите
     «Восстановить». Каналы, которые удалены/заблокированы, получат статус
     «ошибка» — это нормально.
   - **Шаг 3. История** — нажмите «Восстановить историю». Процесс долгий
     (~15 сек на видео, можно останавливать и продолжать в любой момент —
     прогресс сохраняется). Удалённые/скрытые видео помечаются «недоступно».
   - **Шаг 4. Видео** — распаковка ваших роликов и страница «мои видео».

5. Проверить результат: в YouTube откройте «Историю» и «Подписки» — данные
   с прошлого канала на месте. Локальные архивы: «архив истории»
   (`/archive`) и «мои видео» (`/memories`) в панели.

## Как это работает технически

- Программа читает zip-части Takeout напрямую (многочастные выгрузки,
  кириллические имена файлов — чинятся автоматически).
- Подписки: из контекста вкладки youtube.com выполняется
  `youtubei/v1/subscription/write` — ровно тот же запрос, что отправляет сайт
  при клике «Подписаться». Куки и заголовок `SAPISIDHASH` берутся из вашей
  сессии; ключей API не требуется.
- История: навигация на `watch?v=…`, беззвучное воспроизведение на заданное
  число секунд (реклама пропускается/переваривается автоматически).
- Всё крутится локально: веб-панель на `127.0.0.1`, никакого трафика в
  третьи сервисы, кроме самого YouTube.

## Важно знать

- **Риск для аккаунта.** Массовая автоматическая подписка/просмотр — это
  автоматизация, которую Google формально не одобряет. Сотни подписок и
  тысячи видео за раз могут привлечь внимание анти-спам систем. Не запускайте
  восстановление на только что созданном аккаунте вместе с другими новыми
  действиями; делайте перерывы (в интерфейсе есть кнопка «Стоп», прогресс
  сохраняется). Вы используете инструмент на свой страх и риск.
- Если канал был заблокирован, часть каналов из подписок могла быть удалена
  или скрыта — они просто не подпишутся (статус «ошибка»).
- Возрастные/гео-ограниченные видео могут не попасть в историю
  (статус «недоступно»).
- Даты старых просмотров YouTube проставит новые. Полная копия истории
  (с датами и назвениями) навсегда остаётся в локальном «архиве истории»
  и в экспорте JSON/CSV.

## Структура

```
main.py               — запуск (CLI: python main.py [папка_с_zip] [--port 8765])
ytsaver/
  takeout.py          — чтение zip-частей Takeout, парсинг подписок/истории
  chrome.py           — поиск/запуск Chrome, минимальный CDP-клиент
  restore.py          — восстановление подписок и истории, распаковка видео
  server.py           — локальная веб-панель (127.0.0.1)
  state.py            — прогресс/состояние (data/state.json)
data/
  videos/             — распакованные ваши видео
  state.json          — прогресс восстановления
  chrome-profile/     — профиль браузера (ваш вход в новый аккаунт)
```

## FAQ

**Виртуальный/proxy?** Браузер использует системный прокси/VPN как обычный
Chrome — если видео открываются в обычном браузере, всё заработает.

**Можно ли перенести историю другому человеку / на канал без входа?** Нет —
история пишется только в аккаунт, в котором выполнен вход и идёт просмотр.

**Экспорт данных?** Панель → «Экспорт»: история JSON/CSV, поиск CSV.
Также «архив истории» — удобная просмотр-страница с превью.
